# Math formulas
## Area
- Circle: S = πR²
- Rectangle: S = ab
- Square: S = a²
- Triangle: S = ah

## Perimeter
- Circle: P = 2πR
- Rectangle: P = 2a + 2b
- Square: P = 4a
- Triangle: P = a + b + c

# Functions
## Area
- Circle:
  Calculating circle's area function.
    ARGUMENTS:
      r (int) - circle's radius
    RETURNS:
      result area
  **area(r)**
- Rectangle:
  Calculating rectangle's area function.
    ARGUMENTS:
      a (int) - rectangle's height
      b (int) - rectangle's width
    RETURNS:
      result area
  **area(a, b)**
- Square: 
  Calculating square's area function.
    ARGUMENTS:
      a (int) - square's lenght
    RETURNS:
      result area
  **area(a)**
- Triangle:
  Calculating triangle's perimeter function.
    ARGUMENTS:
      a (int) - triangle's first side's lenght
      b (int) - triangle's second side's lenght
      c (int) - triangle's third side's lenght
    RETURNS:
      result perimeter
  **area(a, h)**

    ARGUMENTS:

- Rectangle:
  Calculating rectangle's perimeter function.

      result perimeter

- Square:
  Calculating square's perimeter function.
    ARGUMENTS:
      a (int) - square's lenght
    RETURNS:
      result perimeter
**perimeter(a)**
- Triangle:
  Calculating triangle's perimeter function.
    ARGUMENTS:
      a (int) - triangle's first side's lenght
